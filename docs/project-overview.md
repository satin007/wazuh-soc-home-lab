# Project Overview

This project is a hands-on Security Operations Center (SOC) home lab built using Wazuh.

The lab demonstrates how security events generated on a Linux endpoint can be collected, analyzed, and investigated through a SIEM/XDR platform.

## Objectives

- Understand the flow of security logs from an endpoint to a SIEM.
- Detect suspicious user and group creation activity.
- Detect SSH login attempts involving non-existent users.
- Investigate alerts generated by Wazuh.
- Practice basic SOC investigation and incident analysis.

## Technologies Used

- Wazuh
- Ubuntu Linux
- SSH
- Linux authentication logs
- VirtualBox

## Security Scenarios

### Scenario 1 — Suspicious User/Group Creation

A new local user/group was created on the Linux endpoint and monitored through Wazuh.

### Scenario 2 — SSH Login Attempt Using a Non-Existent User

Multiple failed SSH login attempts were generated using a non-existent username. Wazuh detected the activity and generated an alert.
